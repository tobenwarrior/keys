# Sounds

The recordings in `packs/` come from Mechvibes:

https://github.com/hainguyents13/mechvibes

Revision `ac846bc01b9dbb061bf5bc0684c9b1600f618428` (2026-11-02).

That repository is MIT licensed. None of the pack folders adds a separate license, so all 14 keyboard and mouse packs are included. The files here are those recordings stored as 16-bit PCM WAV at 44.1 kHz stereo, so keys can play them with system audio. The slice times in each `config.json` are unchanged.

## Keyboard

- CherryMX Black - ABS keycaps, `packs/keyboard/cherrymx-black-abs`
- CherryMX Black - PBT keycaps, `packs/keyboard/cherrymx-black-pbt`
- CherryMX Blue - ABS keycaps, `packs/keyboard/cherrymx-blue-abs`
- CherryMX Blue - PBT keycaps, `packs/keyboard/cherrymx-blue-pbt`
- CherryMX Brown - ABS keycaps, `packs/keyboard/cherrymx-brown-abs`
- CherryMX Brown - PBT keycaps, `packs/keyboard/cherrymx-brown-pbt`
- CherryMX Red - ABS keycaps, `packs/keyboard/cherrymx-red-abs`
- EG Crystal Purple, `packs/keyboard/eg-crystal-purple`
- EG Oreo, `packs/keyboard/eg-oreo`
- Topre Purple Hybrid - PBT keycaps, `packs/keyboard/topre-purple-hybrid-pbt`

## Mouse

- Chat, `packs/mouse/chat`
- Ping, `packs/mouse/ping`
- Vibrate, `packs/mouse/vibrate`
- Wooden, `packs/mouse/wooden`
